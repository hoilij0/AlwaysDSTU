# Always DSTU

Каркас настольного приложения для лабораторной работы № 5.

## Требования

- Python 3.12 или новее
- Tkinter (входит в стандартную поставку Python для Windows)

## Запуск

Из папки проекта выполните:

```powershell
python main.py
```

Окно содержит название проекта и кнопку-заглушку. Подключение PostgreSQL и
реализация функций расписания относятся к следующим этапам работы.
